# ケアマップ 法務ページ

- プライバシーポリシー: https://muranakar.github.io/care-map-legal/privacy.html

## 編集方法

このリポジトリを直接編集しないこと。**唯一の正はアプリ本体のリポジトリ
（`medical_care_map`）の `legal/`** で、ここはそのミラーです。

```sh
# medical_care_map リポジトリで legal/ を編集したあと
sh tools/publish_legal.sh
```
